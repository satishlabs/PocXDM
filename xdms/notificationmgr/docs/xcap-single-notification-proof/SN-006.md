## Requirement
Changes for different watchers in the same window produce **one bundled send per watcher**. No cross-watcher payload mixing.

## Steps
1. Trigger changes for 3 watchers in the same window.
2. Wait for epoch expiry.
3. Compare `STEP-6A` / `STEP-12` `watcher=` and `dirURI`.

## Expected
- 3 tracker rows
- 3 `STEP-6A` with 3 destIds
- Each `dirURI` belongs to that watcher
