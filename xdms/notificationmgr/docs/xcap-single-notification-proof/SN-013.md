## Requirement
Repeated producer calls for the same watcher must not create a second tracker row or reset `LAST_NOTIFIED_TIME`.

## Steps
1. Tracker row already exists (SN-003).
2. Repeat subscriber updates.
3. Query count and timestamps.

## Expected
One tracker row. Timestamp unchanged until SN-005 claim. `unchangedRows` / `STEP-SF2A already in tracker`.

## Proof commands
```sql
SELECT COUNT(*), MIN(LAST_NOTIFIED_TIME), MAX(LAST_NOTIFIED_TIME)
  FROM DG.MDN_NOTIFY_TRACKER WHERE MDN='805061809210';
```

```bash
grep -nE "STEP-SF2A MDN already in tracker|unchangedRows=" XDMDataMgr.log | tail -15
```
